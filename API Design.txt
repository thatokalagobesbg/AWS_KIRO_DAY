Evaluate Squad Recommendations
Endpoint
POST /api/requests/evaluate

Request
{
  "urgency": "High",
  "startDate": "2026-10-01",
  "endDate": "2026-12-31",
  "roles": [
    {
      "roleId": 1,
      "skills": [101, 102, 103]
    },
    {
      "roleId": 2,
      "skills": [201, 202]
    }
  ]
}

Response
{
  "recommendedMembers": [
    {
      "empId": "12345",
      "empName": "John Smith",
      "role": "Developer",
      "capacity": 80,
      "availability": "Available",
      "ranking": 1,
      "matchScore": 95,
      "rationale": "Strong match for required skills and availability.",
      "skills": [
        "Java",
        "Azure",
        "SQL"
      ]
    }
  ]
}

API Structure:
--form dropdowns
GET    /api/skills
GET    /api/roles

--recommend members
POST   /api/requests/evaluate

--create project with created members
POST   /api/projects

--dashboard
GET    /api/projects

-- project details
GET    /api/projects/{projectId}

-- update project details or members
PUT    /api/projects/{projectId}
